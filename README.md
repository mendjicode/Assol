# АССОЛЬ — альтернативная концепция сайта

Неофициальная демоверсия в направлении soft botanical pop: выразительная типографика и коллажная композиция в спокойной, но контрастной палитре. Первый экран переработан: слоган сокращён до «Цветы с характером», заголовок адаптирован под разные ширины экранов, пересечения строк устранены.

Названия и цены букетов демонстрационные. Контакты и интеграции заказа перед публикацией необходимо согласовать с мастерской.

Для GitHub Pages: загрузите index.html в корень публичного репозитория → Settings → Pages → Deploy from a branch → main → /(root).
Фотографии и шрифты загружаются из внешних источников.
